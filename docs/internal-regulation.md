# 内在调节与经验学习（实验）

这套机制尝试让人物的选择、注意倾向和经验学习受到持续内部过程的影响。它不维护“开心”“愤怒”等情绪标签，也不要求人物按标签表演。人物仍由原有语言模型理解处境、提出行动，并用自己的方式表达经历。

神经递质名称用于标识受生物机制启发的计算通路。所有活性、需要与系数均为无量纲工程变量，不是人体浓度、完整神经科学模型或模型具有主观感觉的证据。学习发生在外部保存的行动预期中，不训练基础 LLM 的权重。

## 一次决策怎样发生

1. 原有行动模型先提出一个**尚未执行**的工具调用。此时没有提交动作，也没有制造工具回执。
2. `Regulation` 评价请求读取人物实际收到的新事件、有限的近期上下文、当前内部状态、已学到的行动预期、完整作者定义和当前可用工具。它解释经历对需要的影响，预测原候选，以及最多两个可行的替代。
3. 程序根据已发生的经历更新内部状态。需要缺口、调制通路与已有学习共同影响候选的需要收益、行动成本、风险、承诺和探索价值。概率加权后的预期效果只是评分输入，评价模型不能直接指定奖励总分或最终赢家。
4. 程序只选择一个工具调用。其他候选保留为调试资料，不进入“已经执行”的历史，也不产生副作用。选中动作仍走原有工具准入、参数检查、调度、确认和平台限制。
5. 该选择的预期在实际结果到达前持久保存。之后根据匹配的真实结果比较预期与实际影响，产生奖励预测误差（RPE），修正同一身份、情境和行动策略的未来预期。

这里的“奖励”取决于当前需要及真实结果。得到熟悉的陪伴可以缓解连接需要，即使结果符合预期、没有明显预测误差；结果意外也不等于一定值得追求。满足与学习分别计算。

### 需要与调制通路

当前需要轴为恢复、可靠连接、自主控制、有效行动与探索。正的经历效果表示相对缓解现有缺口，负值表示缺口增加。这些是对已感知处境的内部评价，不会自行改写饥饿、伤势或睡眠等身体事实。

多巴胺样、去甲肾上腺素样、血清素样、阿片样、催产素样通路分别保留持续背景活性（tonic）、短暂变化（phasic）和适应程度（adaptation）。程序按**世界时间**计算衰减、积累、饱和与恢复，再由这些通路共同影响计算增益。不存在“一种递质等于一种情绪”的固定映射，推理快慢也不能直接决定反应衰退速度。

重复刺激经过来源去重和同一段经历的适应处理。回忆、成长整理、内部状态说明和反复读取同一条消息不能作为新的奖赏来源。持续调用同一工具也不自动等于有了新的有效经历。

首次开启以当前感知窗口为起点，旧事件及其来源不会重新刷入刺激。默认需要缺口为 0.2，背景活性为 0.5；背景、脉冲和适应的半衰期分别为 3600、60、1800 世界秒。这些是待实验调整的工程系数。实际输入足以改变选择并不等于已经验证了长期拟人效果。

### 预期学习的边界

- 已确认的自主成功和自主失败都可以修正此前保存的预期。发送成功只证明消息发出，不证明对方接受了邀请或认可了发言。
- 候选区分即时执行确认（`completion`）与等待对方回复（`reply`，仅用于发送消息）。期待对方接纳或回应时，平台明确引用原消息的回复才可关联到该期待；普通近邻消息不能靠时间接近猜测归因，匿名振动也不透露回复关系。没有明确关联或还未回复时，不把等待误记为拒绝或零收益。
- 送达未知、尚未完成或缺少真实结果时，不编造结果来训练。没有事前预测，也不能事后声称“原本就期待如此”。
- 未结算预期保留最多七个世界日，之后停止跟踪，不因此产生失败或拒绝的学习。当前只有程序明确标记的完成/失败结果参与即时学习；多条消息合并的阅读结果缺少逐条效果归属，不直接结算回应期待。明确回复还必须匹配预期中的人物身份；原消息已压缩时，从持久记录取回对应发送意图帮助理解。
- 学习记录保留实际动作、具体策略、情境和身份范围；同名人物、不同帐号或不同聊天频道不能仅因措辞相似而共享预期。
- 被操纵身体的经历可以影响当时内部反应，但不证明自愿、喜欢、同意或已经形成习惯。人类驾驶的操作不能冒充自主模型的候选选择；其叙事仍遵守原有身体操纵与完全入替的区别。
- 长期的关系认识、习惯与性格倾向仍由成长链路基于亲历整理。内部评价本身不是另一件真实经历，不能递归用来给自己的判断补证。

## World 与身体事实

World 继续以当前世界与人物状态为上下文，不因此增加一份聊天式历史。它负责裁定外部事件、可感知身体条件及真实动作结果；内部调节只能解释人物实际收到的材料，不读取隐藏状态、操作者意图或其他人的内心。

性生理反射模拟是独立的可选子系统，默认关闭。启用后，它对明确世界身体感知中的刺激与抑制进行积累，模拟兴奋上升、内部峰值与恢复阶段。聊天文字、图片摘要、行动计划或模型自述不能直接确立这类身体刺激。

这些阶段通过接收增益影响可用注意、行动投入、抑制与恢复的相对权重，恢复后解除作用。世界行动和观察虽通过工具回执交付，仍由程序标明其世界感知来源；普通聊天或应用回执不能自行取得这种来源标记。

**内部阶段不等于 World 已裁定发生了相应身体事件。** 当前模拟不会因为跨过内部阈值，就自动把高潮、身体动作或他人的反应写入世界事实。可观察的身体后果必须经过世界统一的提交路径。身体反应、主观愉悦、自愿和关系认同也不能互相替代。

## 配置

配置位于 `bot.regulation`。实验默认关闭；启用后，每次适用的自主决策会增加一次使用 Bot 模型配置的 `Regulation` 请求。它与原有模型请求遵守相同的端点串行设置，排队时间计入超时。模型调用量与行动延迟因此会增加。

| 配置项 | 默认值 | 含义 |
| --- | --- | --- |
| `enabled` | `false` | 启用内部状态维护、经历评价与预期学习。关闭时保留原有行动链。 |
| `decisionEnabled` | `true` | 允许程序从候选中选择实际动作；关闭后只预测原候选并学习其真实结果，可用于对照实验。 |
| `timeoutMs` | `20000` | 单次评价的现实毫秒上限，包含共享端点排队。范围 1000–300000。 |
| `maxInputChars` | `64000` | 完整评价请求的字符预算，范围 4000–200000。作者边界、候选和实际工具语义不能静默截断；近期材料可以明确标记省略。 |
| `candidateCount` | `3` | 最多比较 1–3 个候选，包含原候选。候选只是预测，只有最终选中项执行。 |
| `learningRate` | `0.3` | 新结果修正相同范围内行动预期的基础速率，范围 0–1；0 暂停预期更新。 |
| `driftRate` | `0` | 每世界小时连接与探索需要的自然增长率，范围 0–0.5；0 只随经历变化。不凭时间自行制造身体饥饿或疲劳。 |
| `sexualResponseEnabled` | `false` | 启用独立的性生理反射内部模拟，不赋予其修改世界事实的权限。 |

例如，可以先开启内部评价，保持原行动候选，观察预测与实际结果是否可靠：

```yaml
bot:
  regulation:
    enabled: true
    decisionEnabled: false
```

再将 `decisionEnabled` 改为 `true`，比较内部机制是否改变实际选择。配置更新遵循插件原有保存与重新加载流程。

评价超时、格式错误、参数无效或输入预算不足时，不制造奖励、虚假动作或结果；行动链可以继续采用通过当前准入检查的原候选。作者定义、感知上下文、生命周期或工具可用性在请求期间变化时，旧结果不得覆盖新的处境。

## 上下文、查看与验证

内部状态和学习依据持久保存。给人物的相关内部变化以新事件追加，当前固定提示词前缀不因每次数值变化而重写；正常上下文压缩时才更新固定摘要。候选比较资料与管理员调试信息不能被伪装成角色实际经历。

`regulation.jsonl` 保存独立的事件日志，并随存档、恢复、重置一同处理；未完成尾部不会被复制成完整存档。运行中的查看页面读取当前内存状态，显示最近记录与学习样本，历史不会按页面容量删除。启动时从事件日志重建；大量长期历史的启动性能仍需在实际部署中测量。

WebUI 的角色与成长界面可以查看内部需要、调制通路、候选比较及学习依据；实时调用页面可以按 `Regulation` 查看实际请求、流式响应和错误。查看界面本身不产生新刺激或触发工具。

评估这套实验时，重点比较实际行为与预测修正，而非情绪词数量：相同经历是否能复现结果，重复输入是否饱和，明确失败后是否调整期待，恢复是否按世界时间推进，身份隔离与接管归属是否保持正确。分别关闭候选选择、预期学习或需要漂移，可以帮助判断变化究竟来自哪个计算过程。
